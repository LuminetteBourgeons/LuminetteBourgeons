# Snake setup

1. Push the repo, then open the **Actions** tab -> **Generate snake** -> **Run workflow**.
2. When it finishes, the `output` branch holds `snake.svg`.
3. In README.md, change the snake image source to:

   `https://raw.githubusercontent.com/LuminetteBourgeons/LuminetteBourgeons/output/snake.svg`

The static `grid-snake.svg` stays in the repo as a fallback.
